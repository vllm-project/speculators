Serving acceptance for two LiLiCorr draft checkpoints, measured with `scripts/evaluate/evaluate.py` (SPEED-Bench qualitative split: 880 conversations, 1,138 requests, thinking enabled, temperature 0 (plus a temperature-1 rerun in the table below), up to 32,768 completion tokens, concurrency 64).

| [`MeganEFlynn/Qwen3.5-4B-speculator.lilicorr`](https://huggingface.co/MeganEFlynn/Qwen3.5-4B-speculator.lilicorr)     | Qwen/Qwen3.5-4B | **9.76**          | 58.4%            | 87.1%      | 42.6%       |

## Temperature sensitivity

The same eval rerun with `temperature: 1` (draft sampling still greedy):

| Draft checkpoint                 | Verifier   | Temp | Acceptance length | Token acceptance | Pos-1 rate | Pos-15 rate |
| -------------------------------- | ---------- | ---- | ----------------- | ---------------- | ---------- | ----------- |
| Qwen3.5-4B-speculator.lilicorr   | Qwen3.5-4B | 0    | **9.76**          | 58.4%            | 87.1%      | 42.6%       |
| Qwen3.5-4B-speculator.lilicorr   | Qwen3.5-4B | 1    | 3.39              | 15.9%            | 60.0%      | 3.9%        |
| Qwen3-4B-LiLiCorr-b16-regen-100k | Qwen3-4B   | 0    | **5.76**          | 31.7%            | 80.7%      | 6.7%        |
| Qwen3-4B-LiLiCorr-b16-regen-100k | Qwen3-4B   | 1    | 3.22              | 14.8%            | 69.2%      | 0.6%        |

Sampling from the verifier's flat distribution matches the drafter's greedy proposals far less often, as expected; acceptance length stays above 3 in both cases, so spec decode remains net-positive under sampling. The temperature-1 runs also hit the 900-second per-request timeout more often (the Qwen3.5-4B run completed 1,012 of 1,138 requests; timeouts are excluded from the pooled statistics).

## Setup

- vLLM 0.31.0, `--speculative-config '{"method":"dflash","num_speculative_tokens":15,"draft_sample_method":"greedy"}'`
- `--per-request-spec-decode-metrics summary` so per-request acceptance histograms reach the eval client
- Qwen3.5-4B server: single GPU, max model len 65,536
- Qwen3-4B server: 4-way tensor parallel, max model len 40,960
- Report pooled from per-request acceptance histograms; requests whose prompt plus the completion budget exceeded the verifier's context were rejected by the server (9 for Qwen3-4B, 79 for Qwen3.5-4B at 65,536) and are excluded from the pooled statistics

```bash
# Qwen3.5-4B
vllm serve Qwen/Qwen3.5-4B --port 8025 --max-model-len 65536 \
    --speculative-config '{"method":"dflash","model":"MeganEFlynn/Qwen3.5-4B-speculator.lilicorr","num_speculative_tokens":15,"draft_sample_method":"greedy"}' \
    --per-request-spec-decode-metrics summary
python scripts/evaluate/evaluate.py acceptance \
    --model Qwen/Qwen3.5-4B --url http://localhost:8025 \
    --output-artifact-dir output/lilicorr_qwen35_4b \
    --extra-inputs '{"temperature":0,"chat_template_kwargs":{"enable_thinking":true},"max_completion_tokens":32768}'

# Qwen3-4B
vllm serve Qwen/Qwen3-4B --port 8026 --max-model-len 40960 --tensor-parallel-size 4 \
    --speculative-config '{"method":"dflash","model":"MeganEFlynn/Qwen3-4B-LiLiCorr-b16-regen-100k","num_speculative_tokens":15,"draft_sample_method":"greedy"}' \
    --per-request-spec-decode-metrics summary
python scripts/evaluate/evaluate.py acceptance \
    --model Qwen/Qwen3-4B --url http://localhost:8026 \
    --output-artifact-dir output/lilicorr_qwen3_4b \
    --extra-inputs '{"temperature":0,"chat_template_kwargs":{"enable_thinking":true},"max_completion_tokens":32768}'
```

## Reading the numbers

Both drafters were trained for one epoch on roughly 100k open-perfectblend-style conversations. The difference is who regenerated the responses: the Qwen3.5-4B drafter's corpus was regenerated **on-policy by Qwen3.5-4B itself** (per its model card), while the Qwen3-4B drafter's corpus was regenerated by Qwen3-8B — off-policy for its verifier. Both corpora's assistant turns carry Qwen3-style reasoning content (the regenerated responses open with thinking-style text; no literal `<think/>` tags, which the chat template supplies). The Qwen3.5-4B drafter's acceptance holds up across the full 15-position block (42.6% still accepting at position 15); the Qwen3-4B drafter decays earlier, consistent with the off-policy distribution shift.

For reference, the Qwen3-4B checkpoint's teacher-forced validation metrics were lilicorr EAL 5.19 vs top-1 EAL 4.45 (oracle 8.13); the Qwen3.5-4B checkpoint's were lilicorr EAL 7.10 vs top-1 EAL 6.16 (oracle 9.58). The served acceptance lengths sit below the teacher-forced EAL in both cases, the expected free-running vs teacher-forced gap.
