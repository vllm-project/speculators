# Learning rates

Base-training sweeps over LR, Muon LR, the ratio between them, schedule shape, and warmup fraction.

Report the full curve, not just the winner — whether the optimum is a sharp peak or a plateau edge changes how much the recommendation can be trusted at a different scale. If the best value sits at the edge of the range tried, say so; the real optimum may be outside it.

Fine-tuning LR sweeps belong in [finetuning experiments](../../finetuning-experiments/index.md). The optima differ by roughly an order of magnitude, so the two must not be read together.

Start from the [hyperparameter sweep template](../TEMPLATE.md); the rules are on the [category page](../index.md).
